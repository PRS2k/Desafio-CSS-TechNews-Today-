# 📱 TechNEWS Today

Um portal de notícias sobre tecnologia desenvolvido em HTML e CSS, focado em apresentar as principais novidades do mundo tech de forma simples, direta e organizada.

---

## 🚀 Sobre o Projeto

O **TechNEWS Today** é uma aplicação web que simula a página inicial de um portal de notícias tecnológicas. Desenvolvido como um projeto prático de fixação de conceitos web, o site reúne:

- 📰 **Notícia em destaque:** Artigo principal sobre os avanços e novidades em Inteligência Artificial.
- 📺 **Mídia integrada:** Seção interativa com vídeo do YouTube incorporado via `<iframe>`.
- 📧 **Captura de leitores:** Formulário completo de inscrição para newsletter.
- 📅 **Metadados:** Exibição da data de publicação dos artigos.
- 📩 **Rodapé informativo:** Links e dados de contato.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo (`<header>`, `<article>`, `<section>`, `<footer>`, etc.).
- **CSS3:** Estilização visual, hierarquia de fontes, cores e espaçamentos.
- **YouTube Embed API:** Incorporação de reprodutor de vídeo direto na página.
